# 개발 안내

[README로 돌아가기](../README.md)

## 실행 환경

로컬 검증 환경은 Node.js 24.x와 npm입니다. 프로젝트는 ES 모듈과 Node.js 기본 모듈만 사용합니다. 별도 npm 의존성·설치 단계·번들러·빌드 명령이 없습니다. 브라우저에서 쓰는 Three.js와 OrbitControls는 `dist/vendor/`에 함께 들어 있습니다.

```sh
npm start
npm test
```

위 명령은 각각 서버 실행과 자동 검사입니다. 서버를 켠 터미널과 별도의 터미널에서 테스트를 실행하거나, 서버를 종료한 뒤 테스트하세요.

## 파일별 역할

| 파일 | 역할 |
| --- | --- |
| `dist/index.html` | 한국어 화면 구조, 대화상자, import map |
| `dist/style.css` | 화면 디자인, 반응형 배치, 열화상 UI |
| `dist/app.js` | Three.js 장면, 입력 이벤트, 실행 상태, 온도계, 노트 저장 |
| `dist/physics.js` | `HeatModel`, 재료 계수, 가열·냉각·열 교환 |
| `dist/conduction.js` | 고체 형상, 연결 그래프, 판의 온도 텍스처 |
| `dist/temperature-field.js` | 물·공기 온도장, 보간, 대류·작은 입자 운동, 복사 위치 |
| `dist/temperature-material.js` | 연속 온도 표면과 열화상 셰이더 |
| `dist/flow-tracers.js` | 인스턴스 구슬 입자와 짧은 꼬리 |
| `dist/vendor/` | Three.js 0.170.0, OrbitControls, MIT 라이선스 |
| `server.mjs` | `dist/`를 제공하는 개발용 HTTP 서버 |
| `tests/physics.test.mjs` | Node.js 기본 테스트 러너 기반 모형 검사 |

`dist/`를 원본으로 수정하고 Git에 포함합니다. 변경 후 브라우저를 새로고침하면 반영됩니다. 별도 소스에서 `dist/`를 재생성하는 구조가 아닙니다.

## 상태와 데이터 흐름

`app.js`가 실험별 `HeatModel`을 만들고, 실행 중에는 프레임 경과 시간에 배속을 곱해 `step()`에 전달합니다. 모형의 온도·위상·온도장을 3D 물체, 입자, 온도계, 그래프에 반영합니다.

탐구 노트는 `ongi-notes-v1` 키로 `localStorage`에 저장합니다. 기록에는 실험명, 조건 문자열, A·B·C 온도, 관찰 글, 작성 시각이 들어갑니다. 기존 키나 저장 구조를 바꿀 때는 기존 노트에 미치는 영향을 확인하세요.

## 성능 설정

기본 절전 모드는 픽셀 비율 1, 최대 30fps이며 상세 모드는 최대 60fps·픽셀 비율 1.5입니다. 대류 구슬은 절전 36개·상세 60개, 고체 입자는 66개·132개입니다. 복사 표시는 36개·72개입니다. 실제 달성 프레임 수는 기기에 따라 달라집니다.

대류 구슬은 인스턴스 메시, 꼬리는 선 세그먼트로 묶습니다. 정지 중에는 화면 변화가 있을 때 렌더링하고, 숨겨진 탭에서는 애니메이션을 취소합니다. 장면을 바꿀 때 기하·재질·온도 텍스처를 해제합니다. 그림자·후처리 효과는 사용하지 않습니다.

## 자동 검사

`npm test`는 다음 성질을 검사합니다.

- 직선·ㄱ자·고리·판의 전도 연결과 대칭, 판 내부 열 교환 보존
- 모든 모양·재료의 온도 범위, 재료별 가열 순서, 초기화
- 아래/위 가열, 열원 좌우 이동·높이 변화와 대류 방향
- 온도장 텍스처와 온도계의 일치
- 큰 대류가 없을 때의 작은 입자 운동, 용기 경계, 동일 시점의 재현성
- 복사의 거리·흡수율·가림판·역방향 순 교환
- 배속에 따른 계산 결과의 일관성

`.github/workflows/ci.yml`은 push와 pull request에서 같은 검사를 실행합니다. 패키지 잠금 파일이나 npm 설치가 필요하지 않아 캐시는 설정하지 않았습니다.

## 화면 수동 확인

물리 계산을 바꿨다면 자동 검사를 실행하고 관련 장면을 브라우저에서도 확인하세요. 화면 조작만 바꿨다면 해당 조작과 연결된 기능을 중심으로 확인합니다.

1. 네 실험 탭에서 3D 화면·가열·초기화가 동작하는지 확인합니다.
2. 조건 변경 시 초기화 규칙이 [사용 안내](USER_GUIDE.md)와 일치하는지 확인합니다.
3. 일반/열화상, 화살표·입자, 절전 모드를 전환합니다.
4. 열원을 드래그·방향키로 이동하고 입자·온도계·따뜻한 영역의 위치를 확인합니다.
5. 노트 생성·수정·삭제·새로고침 후 복원·텍스트 다운로드를 확인합니다.
6. 탭 전환 후 일시정지, 시점 초기화·전체 화면을 확인합니다.
7. 예를 들어 1366×768과 390×844 화면에서 가림·잘림을 확인합니다. 실제 학교 기기도 별도로 확인합니다.

## 서버와 배포의 구분

기본 서버는 `127.0.0.1`에만 연결하고 `PORT` 또는 기본 4188번 포트를 사용합니다. `dist/` 밖의 파일은 제공하지 않으며, 알 수 없는 경로는 404로 처리합니다. 운영용 서버 기능이나 사용자 인증·API는 포함하지 않습니다. 공개 배포에는 [정적 호스팅](DEPLOYMENT.md)을 사용하세요.

## 기여할 때

변경 목적과 영향을 설명하고, 실제로 수행한 검사 결과를 함께 기록하세요. 코드의 동작·지원 기능을 바꾸면 관련 문서도 갱신합니다. 외부 라이브러리를 교체할 때는 import 경로와 라이선스 원문을 함께 확인하세요. 프로젝트 자체의 재사용 조건은 아직 별도 라이선스로 지정되어 있지 않습니다.
