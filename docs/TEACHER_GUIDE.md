# 수업 활용 안내

[README로 돌아가기](../README.md)

대상은 초등학교 5학년 과학 학습자입니다. 아래 활동은 수업 구성 예시이며 특정 교과서의 차시나 성취기준에 대한 공식 인증 자료는 아닙니다.

## 학습 목표

- 연결된 고체에서 열이 퍼지는 모습을 관찰하고 재료에 따른 차이를 설명합니다.
- 액체·기체의 아래 가열과 위 가열을 비교하고 큰 순환을 설명합니다.
- 복사에서 거리·표면·가림판이 받는 물체의 온도에 주는 영향을 비교합니다.
- 한 번에 한 조건만 바꾸고 같은 시간의 결과를 기록합니다.

## 수업 전 준비

교사용·학생용 기기에서 3D 화면이 열리는지 확인합니다. 크롬북에서는 기본 절전 모드로 시작하세요. 물리 모형을 모두 한 차시에 깊이 다루기보다 한 가지 현상을 골라 탐구하는 구성이 적합합니다. 모형 값과 실제 측정값의 차이를 먼저 안내하고, 노트 파일을 제출할 장소를 정합니다.

## 40분 수업 예시: 아래에서 데우기와 위에서 데우기

| 시간 | 활동 | 교사 안내 |
| --- | --- | --- |
| 5분 | 따뜻한 물이 어디로 움직일지 예상 | 이유를 먼저 말하게 하고 정답을 서둘러 제시하지 않기 |
| 5분 | 조작 익히기 | 액체 탭, 가열·일시정지, 열화상, 탐구 노트 사용 |
| 10분 | 아래 가열 관찰 | 가열 세기를 고정하고 10·30·60초의 A·B·C 모형 온도 기록 |
| 10분 | 위 가열 비교 | 초기화 여부 확인, 같은 세기·시간으로 관찰 |
| 5분 | 결과 설명 | 색·온도·화살표·입자의 움직임을 근거로 설명 |
| 5분 | 정리와 저장 | 작은 입자 운동과 큰 순환을 구분하고 노트 내려받기 |

표의 초는 화면에 표시된 모형의 경과 시간입니다. 배속을 쓰더라도 비교할 때는 같은 모형 시간에서 기록하세요.

## 다른 탐구로 확장하기

| 탐구 질문 | 바꾸는 조건 | 같게 유지할 조건 | 관찰 초점 |
| --- | --- | --- | --- |
| 구리·철·나무는 어떻게 다를까? | 재료 | 모양, 세기, 경과 시간 | 가운데 지점의 온도 변화 |
| ㄱ자로 꺾어도 열이 전달될까? | 직선/ㄱ자 모양 | 재료, 세기, 경과 시간 | 빈 공간을 가로지르지 않고 이어진 길을 따라 전달 |
| 고리에서는 어느 방향으로 퍼질까? | 양쪽 경로 관찰 | 재료, 세기 | 같은 거리의 A·B 온도 |
| 열원을 올리면 어디가 순환할까? | 열원 높이 | 좌우 위치, 세기, 시간 | 열원 위쪽의 순환과 아래쪽 영역 |
| 멀리 두면 덜 따뜻해질까? | 복사 거리 | 표면, 세기, 시간, 가림판 없음 | 받는 물체 온도 |
| 표면에 따라 가열이 달라질까? | 검고 무광/반짝이는 금속 | 거리, 세기, 시간 | 받는 물체 온도 |
| 따뜻해진 뒤 가리면 어떻게 될까? | 가림판 유무 | 같은 실험을 이어서 진행 | 가열 후 가림판을 넣었을 때 냉각 |

모양별 부피·경로가 다르므로 서로 다른 모양의 온도로 열전도율을 정량 비교하지 않습니다. 물과 공기는 같은 단순화된 대류 모형을 사용하므로 실제 가열 속도의 차이를 비교하는 활동에도 사용하지 않습니다.

## 학생 기록 양식

```text
탐구 질문:
나의 예상과 까닭:
바꾼 조건:
같게 유지한 조건:

실험 1 조건:
모형 경과 시간:
A / B / C 온도:
색·입자·화살표에서 관찰한 점:

실험 2 조건:
모형 경과 시간:
A / B / C 온도:
실험 1과 달라진 점:

관찰을 근거로 한 설명:
이 모형만으로 알 수 없는 점:
다음에 확인하고 싶은 점:
```

## 오개념을 점검하는 질문

- 위를 데웠을 때 큰 순환이 적으면 입자는 모두 멈출까요? 작은 운동과 큰 순환을 나누어 설명하게 합니다.
- 액체·기체에는 대류만 있을까요? 이 앱은 대류를 중심으로 보여 주며 실제 현상에서는 여러 열 전달 방식이 함께 나타날 수 있습니다.
- 열화상에 보이는 물 내부가 실제 카메라 영상일까요? 모형 단면이라는 점을 확인합니다.
- 검게 보이는 모든 재료가 같은 속도로 데워질까요? 앱의 두 표면은 흡수율 차이를 단순화한 조건입니다.
- 화면의 60초·50°C를 실제 실험과 그대로 비교해도 될까요? 실제 물성·질량·환경에 맞춰 보정되지 않았음을 설명합니다.

평가에서는 숫자를 맞혔는지보다 조건 통제, 관찰 근거, 설명의 일관성을 살펴보세요. 계산 범위는 [물리 모형과 한계](PHYSICS_MODEL.md)에 정리되어 있습니다.
