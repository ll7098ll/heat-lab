# 사용 안내

## 실행

배포된 사이트는 브라우저에서 엽니다. 로컬에서는 저장소 루트에서 `npm start`를 실행하고 [http://127.0.0.1:4188](http://127.0.0.1:4188)에 접속합니다. WebGL2를 지원하는 Chrome 또는 Edge가 필요합니다.

## 공통 조작

| 조작 | 동작 |
| --- | --- |
| 상단 실험 탭 | 새 실험을 선택하고 초기 상태로 전환 |
| 가열 시작 / 일시정지 / 계속 가열 | 실험 진행과 정지. 정지 중에는 입자의 작은 운동도 멈춤 |
| 처음으로 | 현재 실험 조건을 유지하고 온도 20°C·시간 0으로 초기화 |
| 가열 세기 | 1–5단계 조절. 실행 중에도 변경 가능 |
| 1× / 2× / 4× | 실험 시간의 진행 배속 변경 |
| 화면 드래그 / 마우스 휠 | 3D 시점 회전 / 확대·축소 |
| 시점 초기화 | 실험을 보는 방향과 확대 상태 복원 |
| 크게 보기 | 실험 패널을 전체 화면으로 표시 |
| 열화상 보기 / 일반 화면 | 같은 모형 온도를 다른 색으로 관찰 |
| 눈에 보이게 | 방향 화살표·입자·크롬북 절전 모드 선택 |

다른 탭으로 이동하거나 실험 안내·탐구 노트를 열면 실험이 일시정지됩니다. 돌아온 뒤 **계속 가열**을 눌러 진행하세요.

## 실험별 사용법

### 고체의 전도

1. **차례차례, 전도** 탭을 선택합니다.
2. 직선 막대·ㄱ자 막대·고리·넓은 판 중 모양을 고릅니다.
3. 구리·철·나무 중 재료를 고르고 가열합니다.
4. A·B·C 온도와 열이 퍼지는 경로를 살펴봅니다.

재료의 차이는 같은 모양·가열 세기·경과 시간에서 비교하세요. 고리의 A·B는 열원에서 양쪽으로 같은 거리에 있습니다. 넓은 판은 가로·세로 방향의 퍼짐을 보여 줍니다. 모양마다 부피와 경로가 다르므로 가열 속도를 정량적으로 비교하지 않습니다.

### 액체·기체의 대류

1. **빙글빙글, 대류** 또는 **공기도 함께, 대류** 탭을 선택합니다.
2. **아래쪽**에서 가열하고 따뜻한 부분의 상승과 주변의 하강을 관찰합니다.
3. **위쪽**으로 바꾼 뒤 같은 시간 동안 가열해 온도 분포를 비교합니다.
4. 화면의 **열원 이동** 손잡이나 열원을 직접 끌어 좌우·상하 위치를 바꿉니다.

키보드로 조작할 때는 `Tab`으로 **열원 이동** 손잡이에 초점을 맞춘 뒤 방향키를 누릅니다. 열원 이동은 새 위치에서 20°C부터 비교하도록 초기화됩니다. 드래그 중에는 시점 회전이 멈추며, 드래그가 끝나면 이전의 실행 상태로 돌아갑니다. 방향키로 옮긴 경우에는 다시 가열을 시작하세요.

구슬의 작은 불규칙 운동과 큰 대류 순환을 구분하세요. 위를 데워 큰 순환이 생기지 않아도 작은 운동은 유지됩니다. 꼬리는 순환이 나타날 때 표시됩니다.

### 복사

1. **공간을 건너, 복사** 탭을 선택합니다.
2. 거리를 1–4칸 사이에서 조절하고 같은 시간의 받는 물체 온도를 비교합니다.
3. **검고 무광**과 **반짝이는 금속** 표면을 비교합니다.
4. 물체가 따뜻해진 뒤 **반사 가림판 넣기**를 켜 온도가 내려가는지 관찰합니다.

거리는 실제 미터 단위가 아닌 모형의 상대 거리입니다. 가림판은 직접 복사를 완전히 차단하는 이상적인 반사판으로 표현합니다.

## 조건을 바꿀 때

| 변경 항목 | 온도·시간 초기화 | 진행 상태 |
| --- | --- | --- |
| 실험 탭 | 새 실험을 20°C·0초로 설정 | 정지 |
| 모양·재료·아래/위 가열·표면·거리 | 초기화 | 정지, 다시 가열 필요 |
| 열원 드래그 | 실제 이동이 시작되면 초기화 | 놓으면 드래그 이전 실행 상태로 복귀 |
| 열원 방향키 이동 | 초기화 | 정지, 다시 가열 필요 |
| 가열 세기·반사 가림판 | 초기화하지 않음 | 현재 실행 상태 유지 |
| 배속·열화상·화살표·입자·절전 모드 | 초기화하지 않음 | 현재 실행 상태 유지 |

가열 세기나 가림판을 바꾸어 별개의 조건을 비교하려면 **처음으로**를 눌러 초기 조건을 맞추세요. 따뜻해진 물체에 가림판을 넣어 냉각을 관찰할 때는 초기화하지 않습니다.

## 열화상 읽기

- 눈금은 항상 20–100°C입니다. 화면마다 자동으로 범위를 늘리지 않습니다.
- 색은 계산한 온도이며 물체 자체가 실제로 그 색으로 변한다는 뜻은 아닙니다.
- 물·공기는 내부를 관찰하기 위한 모형 단면입니다. 실제 카메라로 촬영한 영상이 아닙니다.
- 반짝이는 금속도 주변 반사 영상 대신 모형의 온도를 표시합니다.

표시 원리와 생략된 현상은 [물리 모형과 한계](PHYSICS_MODEL.md)를 참고하세요.

## 탐구 노트

1. 원하는 시점에 **지금 관찰한 것 기록하기**를 누릅니다.
2. 실험 조건·경과 시간·A·B·C 온도가 기록되면 관찰 내용을 입력합니다.
3. 상단 **탐구 노트**에서 수정하거나 개별 기록을 삭제할 수 있습니다.
4. **노트 내려받기**로 `온기실험실-탐구노트.txt`를 저장합니다.

최대 100개 기록, 기록당 관찰 글 3,000자를 지원합니다. 기록은 현재 브라우저의 저장 공간을 사용합니다. 브라우저 데이터 삭제·시크릿 창 종료·학교 기기 초기화 등으로 사라질 수 있습니다. 다른 주소나 포트에서 열면 기존 노트가 보이지 않을 수 있습니다. 내려받은 텍스트를 앱에 다시 가져오는 기능은 없습니다.

## 문제 해결

| 증상 | 확인 방법 |
| --- | --- |
| 3D 화면을 불러오지 못함 | WebGL2 지원, 브라우저 그래픽 가속, 학교 기기의 관리 설정 확인 |
| 파일을 더블클릭했더니 빈 화면 | `npm start` 후 HTTP 주소로 접속 |
| 움직임이 느림 | 크롬북 절전 모드를 켜고 다른 무거운 탭을 닫기 |
| 돌아왔는데 실험이 멈춰 있음 | 탭 전환·안내·노트 열기의 자동 일시정지 여부 확인 후 계속 가열 |
| 이전 노트가 보이지 않음 | 주소·포트·브라우저가 같은지 확인하고 내려받은 기록 확인 |
| 저장 공간 부족 알림 | 노트를 먼저 내려받고 불필요한 기록 삭제 |
| `EADDRINUSE` 오류 | 다른 포트로 실행하거나 같은 포트를 쓰는 기존 서버 종료 |
| 다른 기기에서 로컬 주소 접속 불가 | 기본 서버는 이 컴퓨터만 접속 가능. 공유하려면 [정적 배포](DEPLOYMENT.md) 이용 |
